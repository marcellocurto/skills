# Agent Instructions

Design and maintain all skills in this repository for use with the GPT-5.6 model family. Follow current GPT-5.6 prompting guidance when creating or revising a skill.

Keep `.claude-plugin/plugin.json` synchronized when adding, removing, or renaming a skill. Every repository skill must be listed in its `skills` array so installers group it under "Marcello Curto Skills" rather than "Other."
